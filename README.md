# Складно

Ежедневная головоломка со складыванием бумаги. На двустороннем листе в клетку
напечатаны кусочки картинки дня (пейзаж в духе японской гравюры) и обманки.
Нужно сложить лист по линиям так, чтобы сверху собралась картинка, — ровно за N сгибов.
Лист можно переворачивать. Когда картинка собрана, на неё ставится печать со словом дня,
а картинка уходит в альбом.

Уровни и картинки генерируются сами по дате, прямо в браузере, без сервера.
Понедельник самый лёгкий (3×3, 2 сгиба), воскресенье самое сложное (5×5 → 3×3, 4 сгиба).

## Как устроено

| Файл | Что делает |
|---|---|
| `index.html`, `style.css`, `src/main.js` | интерфейс: лист в 3D (CSS), жест «потяни», переворот, подсказки, печать, итоги, альбом |
| `src/game.js` | партия: сгибы и перевороты, отмена, «заново», подсказка, решено / «переверни» / тупик |
| `src/progress.js` | серия дней, статистика, альбом, текст «поделиться» |
| `src/tutorial.js` | обучение: четыре мини-уровня |
| `src/picture.js` | картинка дня: SVG-пейзаж по seed (гора, луна, сакура, тории, журавли) |
| `src/version.js` | версия сборки (ставит `npm run bump`) |
| `src/fold.js` | модель листа: стопки слоёв, лицо и оборот, поворот рисунка, переворот листа |
| `src/level.js` | что видно сверху, собрана ли картинка |
| `src/solver.js` | перебор всех сгибов и переворотов: что достижимо и за сколько минимум |
| `src/generator.js` | печатает кусочки и обманки так, чтобы картинка собиралась ровно за N сгибов и одним способом |
| `src/daily.js` | дата → seed → уровень, бумага, картинка; сложность по дню недели; слова по датам |
| `src/words.js` | **слова дня (можно с записками и датами) — их нужно заменить на свои** |

## Команды

```bash
npm test                         # тесты (нужен только Node.js, зависимостей нет)
npm run preview                  # уровень на сегодня в терминале
npm run preview -- 2026-11-08    # на конкретный день
npm run preview -- week          # на неделю вперёд
npm run bump                     # новая версия файлов — перед каждым пушем, меняющим сайт
```

**Перед пушем всегда `npm run bump`.** GitHub Pages разрешает браузерам кэшировать файлы
на 10 минут; без новой версии у игрока смешаются старые и новые файлы. Тест `site.test.js`
проверяет, что версии в `index.html` согласованы.

## Запустить у себя

```bash
python3 -m http.server 8000     # и открыть http://localhost:8000
```

Из файла (`file://`) не запустится: браузер не грузит модули без сервера.

Параметры адреса для отладки:

- `?date=2026-11-08` — уровень другого дня;
- `?play=solution` — сразу решить; `?play=x2s,y1e,f` — сразу сделать действия
  («x2s» — вертикальная линия после 2-го столбца, левая часть направо;
  «y1e» — горизонтальная после 1-й строки, нижняя часть вверх; «f» — перевернуть лист);
- `?demo=solution` — то же, но с анимацией;
- `?tutorial` или `?tutorial=2` — открыть обучение (с нужного шага).

Прогресс дня, серия, альбом и пройденное обучение хранятся в `localStorage` браузера.

## Слова дня

В `src/words.js` — список слов, по одному на день, по кругу. Можно добавить записку
(появится в итогах и в альбоме) и привязать слово к дате:

```js
'МОРЕ',
{ word: 'ПЛЕД', note: 'Сегодня вечер под пледом' },
{ word: 'ТОРТ', note: 'С днём рождения!', date: '2026-12-24' },
```

Репозиторий публичный: всё в `src/words.js` может прочитать кто угодно.
