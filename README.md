# Складно

Ежедневная головоломка со складыванием бумаги. Нужно сложить полоску так,
чтобы сверху получился узор-образец. Когда узор совпал, на бумаге проступает слово дня.

Уровни генерируются сами по дате, прямо в браузере, без сервера.
Понедельник самый лёгкий, воскресенье самое сложное.

## Как устроено

| Файл | Что делает |
|---|---|
| `index.html`, `style.css`, `src/main.js` | интерфейс: бумага, сгиб пальцем и кнопками, обучение, итоги дня |
| `src/game.js` | партия: ходы, отмена, «заново», подсказка, решено или тупик |
| `src/progress.js` | серия дней, статистика, текст «поделиться» |
| `src/tutorial.js` | обучение: три мини-уровня |
| `src/version.js` | версия сборки (ставит `npm run bump`) |
| `src/fold.js` | модель листа и сгиба: стопки слоёв, лицо и изнанка |
| `src/level.js` | что видно сверху, решён ли уровень, какие буквы проступили |
| `src/solver.js` | перебор всех сгибов: что достижимо и за сколько минимум |
| `src/generator.js` | строит уровень под слово так, чтобы решение было ровно за N сгибов и только с этим словом |
| `src/daily.js` | дата → seed → уровень; сложность по дню недели |
| `src/words.js` | **слова дня (можно с записками) — их нужно заменить на свои** |

## Команды

```bash
npm test                         # тесты (нужен только Node.js, зависимостей нет)
npm run preview                  # уровень на сегодня в терминале
npm run preview -- 2026-11-08    # на конкретный день
npm run preview -- week          # на неделю вперёд
npm run bump                     # новая версия файлов — перед каждым пушем, меняющим сайт
```

**Перед пушем всегда `npm run bump`.** GitHub Pages разрешает браузерам кэшировать файлы
на 10 минут; без новой версии у игрока смешаются старые и новые файлы. Тест `site.test.js`
проверяет, что версии в `index.html` согласованы.

## Запустить у себя

```bash
python3 -m http.server 8000     # и открыть http://localhost:8000
```

Из файла (`file://`) не запустится: браузер не грузит модули без сервера.

Параметры адреса для отладки:

- `?date=2026-11-08` — уровень другого дня;
- `?moves=2s,1e` — сразу сделать сгибы («2s» — линия после 2-й клетки, левая часть направо; «1e» — после 1-й, правая налево);
- `?demo=2s,1e` — то же, но с анимацией;
- `?tutorial` — открыть обучение.

Прогресс дня, серия и пройденное обучение хранятся в `localStorage` браузера.

Репозиторий публичный: всё в `src/words.js` может прочитать кто угодно.
